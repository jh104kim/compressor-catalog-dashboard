# Compare Lab UX 아이디어 발상회

## 이번 반영

- **유형 우선 선택**: Re/Ro/Sc를 먼저 정하고 해당 Samsung 모델만 표시한다.
- **직접 가능 Samsung 전용**: 직접 비교 후보가 1개 이상인 Samsung 모델만 선택 목록에 표시한다.
- **직접 비교 후보 전용**: 유형·냉매·측정조건·구동·용량 ±15%·선택 지표가 모두 맞는 경쟁 모델만 표시한다.
- **비교 준비도**: 유형별 Samsung/경쟁 모델 수, 직접 비교 가능한 Samsung 수, 조합 수를 보여준다.
- **공식 자료 리서치 큐**: 선택 불가 모델은 냉매·조건·구동·용량 범위·지표와 함께 조사 대상으로 표시한다.
- **안전 비교 분석**: 조건 안전성·효율 해석·Evidence·포트폴리오 시사점·후속 조치를 같은 Release에서 제공한다.
- **직접 비교 상세 보고서**: 비교 가능 8모델·15건만 유형/COP/EER Recharts와 카드로 표시한다.
- **속도 성능 맵**: 양쪽 공식 속도점이 있는 쌍만 RPM/RPS 차트로 표시하고 나머지는 `DATA_REQUIRED`로 유지한다.

## 추가 분석 UX 후보

| 우선순위 | 아이디어 | 사용자 질문 | 안전 원칙 |
|---|---|---|---|
| 완료 | 비교 불가 사유 요약 | 왜 이 유형은 비교가 안 되나? | 냉매·조건·구동·용량·지표 누락 건수를 분리 |
| P1 | 동일군 분포 | Samsung이 같은 비교군에서 어느 범위인가? | 같은 비교군 안에서만 최소·중앙·최대와 위치 표시 |
| P2 | 용량-효율 산점도 | 용량이 비슷할 때 효율 위치는? | 동일 유형·냉매·조건·구동 필터를 고정 |
| P2 | 출처 신뢰도 오버레이 | 이 결론을 얼마나 믿을 수 있나? | 공식/조사, 신뢰도, 기준일을 함께 표시 |
| P2 | 포트폴리오 기회 지도 | 경쟁 모델은 많은데 Samsung 공백인 곳은? | 모델 수와 GAP/UNKNOWN을 구분 |
| P3 | Reference Lab | 조건 환산 참고값도 별도로 볼 수 있나? | 직접 순위와 완전히 분리하고 승패 표현 금지 |
| P3 | Release 변화 비교 | 지난 Release에서 무엇이 달라졌나? | 추가·삭제·수정과 근거 변경을 구분 |
| P3 | 규제 전환 관점 | 저GWP 전환 위험과 준비도는? | 규제 기준일과 냉매 GWP 출처를 표시 |

## 추천 다음 순서

1. 완료된 비교 불가 사유·리서치 큐·직접 비교 차트를 유지한다.
2. 다음 후보는 **동일군 분포 + 용량-효율 산점도**다. 단, 군 교차 순위는 만들지 않는다.
3. 조건 환산은 별도 **Reference Lab**으로 분리해 직접 비교 화면과 섞지 않는다.
