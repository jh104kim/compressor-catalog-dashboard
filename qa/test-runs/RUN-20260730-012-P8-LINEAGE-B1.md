HTTP 200이었고, 새 페이지 진입에서 정상 렌더됐다. 이후 retries=0 P5 E2E를
독립 실행해 다음과 같이 연속 통과했다.

Chrome 실행 파일을 명시해 테스트했다. 이는 앱 시나리오 실패에 포함하지 않는다.
