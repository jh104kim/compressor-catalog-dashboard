⚠️ file:// 직접 열기 불가

DC 런타임이 fetch(location.href)를 사용하므로 반드시 HTTP 서버를 통해 접근해야 합니다. file:// 프로토콜로 열면 CORS 에러가 발생합니다. React CDN 로딩을 위해 인터넷 연결도 필요합니다.

03 DC FRAMEWORK

DC 프레임워크 구현 방법

support.js가 {{ }} 보간과 <sc-for>/<sc-if>를 React 18로 컴파일한다. 모든 계산 로직은 renderVals()에서 끝내고 결과만 템플릿에 바인딩.

컴포넌트 구조

class Component extends DCLogic {
state = {
view: 'kpi',

};

renderVals() {
// 모든 계산은 여기서
const D = window.COMPRESSOR_DATA;
return {
myLabel: D.meta.asOf,
onClick: () =>
this.setState({view: 'kpi'}),
};
}
}

핵심 제약: {{ }} 안에 임의 JS 실행 불가

산술 연산, 함수 호출, 삼항 연산자는 {{ }} 안에서 작동하지 않습니다. 모든 계산(정렬·환산·포맷팅·필터링)은 renderVals() 안 순수 JS로 끝내고 최종 값만 바인딩하세요.

renderVals() 패턴 예시 — 비교군 신뢰도 바

// ✅ 올바른 방법: renderVals()에서 계산 완료

const color = rel >= 4 ? '#067647' : rel >= 3 ? '#1D6FB8'
: rel >= 2 ? '#E8A100' : '#C13515';

// 5칸 색상 배열을 미리 계산해 전달

});

군 교차 순위 금지

측정조건이 다른 모델을 한 순위표에 섞지 않습니다. benchmarkGroup.reliability ≤ 1인 군은 ⚠️ 경고 배너와 "조건불일치" 배지가 자동 노출됩니다. LG DOE-A 스크롤(COP 4.88~5.00)과 Samsung ARI 스크롤(COP 3.37)은 조건이 달라 직접 비교 불가 — 별도 참고군으로 관리합니다.
